### Step 2: Create the .cir Netlist Files

(Note: The lab manual PDF has a couple of syntax typos in the code on pages 15–16, such as missing VGS 1 0 DC 0v in the Output code and = instead of + in the Transfer code. Use the corrected SPICE netlists below so they simulate without errors.)

#### A) NMOS Output Characteristics (nmos_output.cir)
Plots Drain Current I_D vs. V_DS (0V to 12V) for different V_GS steps (0V to 2V):

NMOS OUTPUT CHARACTERISTICS CODE
VGS 1 0 DC 0v
VX 3 2 DC 0v
VDD 3 0 DC 5v
M1 2 1 0 0 NMOS W=1u L=0.35u
.MODEL NMOS NMOS (LEVEL=3
+TOX=7.9E-9 NSUB=1E17 GAMMA=0.5827871
+PHI=0.7 VTO=0.54455489 DELTA=0
+UO=436.256147 ETA=0 THETA=0.1749684
+KP=2.055786E-4 VMAX=8.3099444E4 KAPPA=0.2574081
+RSH=0.0559398 NFS=1E12 TPG=1
+XJ=3E-7 LD=3.162278E-11 WD=7.046724E-8
+CGDO=2.82E-10 CGSO=2.82E-10 CGBO=1E-10
+CJ=1E-3 PB=0.9758533 MJ=0.3448504
+CJSW=3.77852E-10 MJSW=0.3508721)
.DC VDD 0 12 0.2 VGS 0 2 0.1
.PLOT DC I(VX)
.PROBE
.END

### Step 3: Simulate and Add Trace

1. In PSpice AD, open nmos_output.cir (or nmos_transfer.cir) so it is the active file.
2. Click Simulation -> Run (the blue Play icon).
3. In the waveform window, go to Trace -> Add Trace (or press Insert).
4. Select I(VX) or ID(M1) and click OK.
5. To verify the parameter variations shown in the journal (pages 17–22 of VLSI_EXP1_w_Op.pdf), change one parameter at a time in the .cir file and re-run:
   - Width (W): W=0.5u (ID=155uA), W=1.5u (ID=580uA)
   - Length (L): L=0.15u (ID=1.25mA), L=0.5u (ID=222uA)
   - Threshold Voltage (VTO): VTO=0.54455489 (ID=370uA), VTO=0.44455489 (ID=400uA), VTO=1.2V
   - Transconductance (KP): KP=29E-4 (ID=5.2mA), KP=29.30
   - Oxide Thickness (TOX): TOX=120E-9 (ID=368uA)
   - Body Effect (GAMMA): GAMMA=0.744

### Step 4: Detailed Beginner's UI & Button Walkthrough (OrCAD PSpice A/D)

If you have never used **OrCAD PSpice A/D** before, note that this experiment uses a **text netlist (`.cir`)**, so you do NOT need to drag-and-drop schematic symbols—the code itself defines the NMOS transistor (`M1`), power supply (`VDD`), gate source (`VGS`), and ammeter (`VX`). Follow these exact clicks inside the app:

1. **Launch PSpice A/D:**
   - Click the Windows **Start Menu** -> open the **Cadence / OrCAD** folder -> click **PSpice AD** (or **AMS Simulator**).
2. **Create a New Text File:**
   - Look at the top-left menu bar and click **`File` -> `New` -> `Text File`**.
   - A blank white text editor tab will open inside PSpice A/D.
3. **Paste & Save as a `.cir` File:**
   - Copy the **NMOS Output Characteristics** code from Step 2A above and paste it (`Ctrl + V`) into the blank editor.
   - Click **`File` -> `Save As...`** on the top menu.
   - In the Save dialog, change **"Save as type"** to **`All Files (*.*)`**, type **`nmos_output.cir`** in the **"File name"** box, and click **`Save`**.
4. **Activate the Circuit File (Crucial Step in PSpice A/D!):**
   - Right after saving a text file, the **Run** button in PSpice A/D is still greyed out because PSpice treats it as a plain text file until you open it as a Simulation Circuit.
   - Click **`File` -> `Open Simulation...`** on the top menu (or click **`File` -> `Open...`**, change the bottom **"Files of type"** dropdown from `*.dat` to **`Circuit Files (*.cir)`**).
   - Select your saved **`nmos_output.cir`** file and click **`Open`**.
   - Now look at the top toolbar: the **blue Play triangle icon (`Run`)** is active!
5. **Run the Simulation:**
   - Click **`Simulation` -> `Run`** on the top menu (or click the **blue Play `|>` button** on the toolbar).
   - A black graph area (the **Probe Waveform Window**) will appear with the X-axis ranging from `0V` to `12V` (`VDD`).
6. **Plot the Drain Current Curve (`I(VX)` / `ID(M1)`):**
   - On the top menu bar, click **`Trace` -> `Add Trace...`** (or press the **`Insert`** key on your keyboard, or click the toolbar icon that looks like a **green waveform with a `+` sign**).
   - An **"Add Traces"** dialog box opens. In the left column (**Simulation Output Variables**), scroll and click on **`I(VX)`** (or **`ID(M1)`**).
   - Click the **`OK`** button at the bottom-right of the dialog.
   - You will immediately see the family of NMOS Output Characteristic curves plotted on the screen!
7. **Repeat for Transfer Characteristics & Parameter Changes:**
   - To edit parameters (such as changing `W=1u` to `W=0.5u`), click the **`nmos_output.cir` text tab** on the left side (or `View -> Circuit File`), edit the number, press **`Ctrl + S`** to save, click the **blue Play (`Run`)** button again, and add the trace `I(VX)`.
